# 提交打包

课程要求把本项目放进名为「学号+班级」的文件夹再压缩。学号和班级由提交人自己填写，仓库里不编写具体学号。

示例（把文件夹名换成自己的学号和班级）：

```text
20230001-软件2201/
  backend/
  frontend/
  sql/
  docs/
  docker-compose.yml
  deploy-macos.command
  deploy-windows.bat
  remove-macos.command
  remove-windows.bat
  deploy-local-macos.command
  deploy-local-windows.bat
  remove-local-macos.command
  remove-local-windows.bat
  README.md
```

压缩前排除依赖和构建产物：

- `node_modules/`
- `frontend/dist/` 以及任何 `dist/`
- `backend/target/` 以及任何 `target/`
- `.git/`

照片、`frontend/public/media/videos/` 里的介绍视频、`sql/`、`docs/`（含设计报告、`网站设计报告.pdf` 和截图）、源码和 `docker-compose.yml` 要保留。PDF 按 A4、页边距 2.54 cm、小四、1.5 倍行距导出，批改时可以直接看页数，不必再从 Markdown 转一次。课程压缩包硬上限 50 MB。照片本身大约 9.5 MB；14 个介绍视频合计约 75 MB，连同源码后会超过这个上限。仓库里仍保留这些 MP4，克隆后可以直接播放。若某次提交必须压进 50 MB，再单独决定是否从压缩包排除 `frontend/public/media/videos/`。

在「学号+班级」文件夹的上一级执行：

```bash
zip -r 学号班级-山河纪.zip 学号班级 \
  -x '*/node_modules/*' '*/dist/*' '*/target/*' '*/.git/*' '*/uploads/*'
```

不要把 `node_modules` 或 `target` 打进去。它们可以用 `npm install` 和 `mvn package` 重新得到。
